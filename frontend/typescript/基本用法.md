## 1. tsc编译器
### 1.1 安装

TypeScript 官方提供的编译器叫做 tsc，可以将 TypeScript 脚本编译成 JavaScript 脚本。

```bash
$ npm install -g typescript
```

> 这里安装后写错的代码ide可能依旧没有提示，需要配置tsconfig.json

安装后查看

```bash
$ tsc -v
$ tsc -h 
$ tsc --all
```
### 1.2 编译
- 默认自动对应编译，index.ts => index.js
- --outFile 多文件编译成一个文件
- --outDir 指定保存目录，默认为当前目录
- --target 指定编译后js版本
### 1.3 编译过程的错误
默认错误下依旧进行js编译，怎么处理给到开发者。
也可以通过参数控制生成产物过程遇错不编译,
也可以通过参数检测是否有编译错误（不生成产物）

配置文件

## 2. 类型声明
TypeScript 代码最明显的特征
```ts
let foo:string;
```
```ts
// 报错
let foo:string = 123;
```
```ts
let x:number;
console.log(x) // 报错
```
## 3. 类型推断

TypeScript 的设计思想是，类型声明是可选的，你可以加，也可以不加。即使不加类型声明，依然是有效的 TypeScript 代码，只是这时不能保证 TypeScript 会正确推断出类型。由于这个原因，所有 JavaScript 代码都是合法的 TypeScript 代码。

这样设计还有一个好处，将以前的 JavaScript 项目改为 TypeScript 项目时，你可以逐步地为老代码添加类型，即使有些代码没有添加，也不会无法运行。

```ts
let foo = 123;
```
```ts
let foo = 123
foo = 'abc' // 报错
```
```ts
function toString(num:number) {
  return String(num);
}//函数返回值的类型通常是省略不写的。
```
