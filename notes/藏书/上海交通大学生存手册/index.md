# 上海交通大学生存手册

::: info 说明
《上海交通大学生存手册》由上海交通大学本科生于 **2008 年** 编写，是一份面向在校生的公益性指南，涵盖学习心态、科研、留学与选课、GPA 等「生存技巧」。民间也常称其为「交大生存手册」「大学生自救指南」等。

本站存档为 **2008 原版 PDF**；部分内容可能已过时，可对照下方维护版阅读。
:::
