# VitePress Theme (Sinbad's Website)

This repo runs **VitePress** for the blog. Do **not** modify Hexo files (`_config.yml`, `source/`, `public/`) unless the user explicitly asks.

## Key paths

| Purpose | Path |
|---------|------|
| Site config | `.vitepress/config.mjs` |
| Theme entry | `.vitepress/theme/index.ts` |
| Global styles | `.vitepress/styles/index.css` |
| Font | `.vitepress/styles/font.css` |
| Glass blur nav | `.vitepress/styles/blur.css` |
| Hide dividers / nav font | `.vitepress/styles/hidden.css` |
| Home page styles | `.vitepress/styles/home.css` |
| Link icons | `.vitepress/styles/link.scss` |
| Custom components | `.vitepress/theme/components/` |
| Sidebar data | `.vitepress/fronted.json`, `.vitepress/notes.json` |
| Home page | `index.md` |
| Markdown content | `frontend/`, `notes/` |

## Commands

```bash
npm run docs:dev      # gen sidebar + dev server
npm run docs:build    # production build
npm run gen-sidebar   # regenerate fronted.json from frontend/
```

## Conventions

### Fonts

- **Body / headings**: 霞鹜文楷 Screen via `.vitepress/styles/font.css`
- **Nav logo title**: Luckiest Guy in `hidden.css` — keep unless user asks to change
- Add fonts in `font.css`; import it first in `index.css`
- Prefer npmmirror CDN for Chinese fonts:

```css
@import url('https://registry.npmmirror.com/lxgw-wenkai-screen-web/latest/files/style.min.css');

:root {
  --vp-font-family-base: "LXGW WenKai Screen", "LXGW WenKai", "Noto Serif SC", serif;
}
```

### Colors

Override VitePress CSS variables in `index.css`:

```css
:root {
  --vp-c-brand-1: #4f7dde;
  --vp-c-brand-2: #3a6bc9;
  --vp-c-brand-3: #2d5ab0;
}
.dark { /* dark overrides */ }
```

### Style layering

`index.css` import order matters:

1. `font.css`
2. `hidden.css`
3. `blur.css`
4. `home.css`

Keep changes minimal. Match existing patterns (blur glass, rounded blockquotes, link icons).

### Config notes

- JSON imports use `with { type: 'json' }` (Node 22+)
- `srcExclude` keeps Hexo dirs out of the build — do not remove:

```js
srcExclude: ['**/source/**', '**/public/**', '**/tools/**', '**/scaffolds/**', '**/_config*.yml']
```

- Markdown containers: `::: title`, `::: center`, `::: tip/info` (labels hidden via `container` config)
- Sidebar: auto-generated by `scripts/gen-sidebar.mjs` → `.vitepress/fronted.json`

### Registered components

Use in markdown (already registered in `theme/index.ts`):

| Component | Usage |
|-----------|-------|
| `<sign>` | Yellow underline highlight |
| `<Linkcard>` | External link card |
| `<Card>` | Content card |
| `<Quote>` | Quote block |
| `<Gallery>` | Image gallery |
| `<Search>` | Search UI |
| `<BackToTop>` | Back to top |
| `<ArticleMetadata />` | Auto-injected after h1 |

New components: add under `.vitepress/theme/components/`, register in `theme/index.ts`.

## Workflow

1. Read the target style file before editing
2. Prefer CSS variables over hard-coded colors
3. Test with `npm run docs:build` after non-trivial changes
4. Do not touch Hexo migration files unless asked

## Anti-patterns

- Do not edit `source/_posts/` — that is Hexo output
- Do not add heavy animations; keep the A4-paper / reading-focused feel
- Do not replace Luckiest Guy nav font without user confirmation
- Do not use `import ... assert` — use `with` for JSON imports
